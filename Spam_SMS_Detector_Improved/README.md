# SMS Spam Detector (Improved Beginner Project)

## Scope
This version classifies **English SMS text** as `spam` or `ham` (legitimate). It does **not** classify email yet. Email support needs an email dataset and separate validation; do not claim email detection based on this SMS-only dataset.

## Project files
- `spam.csv` — dataset with `label` and `message` columns
- `train_model.py` — cleaning, stratified train/test split, TF-IDF training, evaluation, and artifact saving
- `app.py` — Streamlit user interface
- `requirements.txt` — Python dependencies
- `spam_model.pkl`, `tfidf_vectorizer.pkl` — generated by training

## Setup (Windows PowerShell)
```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```

If PowerShell blocks activation, run the commands with `.venv\Scripts\python.exe` and `.venv\Scripts\streamlit.exe` directly.

## How it works
1. Load labelled SMS examples from `spam.csv`.
2. Convert text to lowercase and remove non-English letters/punctuation.
3. Split into training and test sets using stratification so class proportions are maintained.
4. Fit TF-IDF on training text only; transform test text without refitting.
5. Train Multinomial Naive Bayes.
6. Evaluate using accuracy, precision, recall, F1-score, and confusion matrix.
7. Save the model and vectorizer; Streamlit loads both to classify new messages.

## Important limitations
- The dataset contains older English SMS messages; modern scam wording, regional language, URLs, and current fraud patterns may differ.
- Preprocessing removes digits and punctuation, which can discard useful scam signals such as phone numbers, currency amounts, and URLs. This is a simple teaching baseline, not a production fraud detector.
- Accuracy alone is misleading because ham messages greatly outnumber spam. Inspect spam recall and false negatives.
- A message labelled ham is not guaranteed safe.
- Do not use this model to make financial, security, or account decisions.
